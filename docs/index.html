Questions

Do I need Harbor to use Inlet or Ferry?

No. Each app works on its own and keeps a small Settings window. Harbor just gathers them in one place.

How do updates work?

Press Update (or Update All). Harbor downloads the app’s release from GitHub, checks its SHA-256 against the catalog, quits the app if it’s running, replaces it in place and opens it again. Nothing is installed until you press the button.

How do settings reach the apps?

Each app ships a small file describing its settings. Harbor reads it, draws the controls, writes your choice into that app’s own preferences and tells the app, which applies it right away.

What does Harbor send over the internet?

Nothing. It reads one public file, catalog.json on this site, to learn the latest versions — at most twice a day, or when you press Check for Updates — and downloads a release only when you install or update.

macOS says it can’t be opened.

Builds aren’t notarized yet. Right-click Harbor and choose Open, or run xattr -dr com.apple.quarantine /Applications/Harbor.app.
